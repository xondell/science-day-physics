## Проверка «двойной клик»

1. Скачать/скопировать папку `science-day-physics` целиком (рядом должны лежать `index.html` и `assets/`).
2. Открыть `index.html` двойным кликом.
3. Нажать `F` для полного экрана.
4. Если браузер спросит про локальные файлы — разрешить; сцены используют только локальные скрипты и шрифты.

**Проверено:** `file://`, 0 сетевых запросов, 0 ошибок консоли, все 9 сцен.
