**Аудитория:** 1–4 классы, ведущий — учитель/лектор  
**Длительность:** 39 минут (35–40 с запасом)  
**Формат:** автономный веб-сайт для ноутбука и проектора, без интернета  
**Рабочая папка:** `/home/wizzlink/Music/science-day-physics`

## 1. Цель и критерии успеха

Сделать переносной интерактивный урок к Международному дню науки, с которым лектор идёт по классам младшеклассников и который:

1. Объясняет физику спорта **простыми словами**, без формул и сложных терминов в основном слое.
2. **Повторяет главное несколько раз** — словами, жестами, вопросами, викториной и финалом.
3. На **каждой** главе имеет **настоящую 3D-сцену** и **смысловое действие**, а не только переход «дальше».
4. Запускается **двойным кликом** на ноутбуке без интернета, CDN и установки.
5. Уверенно работает на проекторе **1366×768** и **1920×1080**; телефон и мобильная вёрстка **не входят в объём** (решение пользователя).

Критерий успеха: лектор открывает `index.html`, нажимает `F`, проходит 9 глав за 39 минут, дети 3–4 раза повторяют три ключевых слова и могут назвать их в финале.

## 3. Педагогическая система

### 3.1. Три секрета

| Слово | Жест | Смысл для ребёнка | Где работает |
|---|---|---|---|
| **СИЛА** | Топнуть ногой | Сильнее оттолкнулся — быстрее полетел | Футбол, спринт, шест, велосипед |
| **ВРАЩЕНИЕ** | Покрутить рукой | Закрутил — мяч полетел по дуге | Футбол, теннис, баскетбол |
| **ТОЧНОСТЬ** | Показать на цель | Попал в угол/вовремя — получил результат | Футбол, старт, прыжок, плавание |

### 3.2. Пять обязательных точек повтора

1. **Глава 2:** первое называние + жест, хором 2 раза.
2. **Глава 3 (футбол):** «Какое слово свернуло мяч? — ВРАЩЕНИЕ. Повторим…»
3. **Разминка** (кнопка в шапке, не слайд): встать, 3 жеста, 2 круга.
4. **Перед викториной:** «Закройте глаза. Три слова?» → открыть и проверить.
5. **Финал:** «Скажи соседу три слова и покажи три жеста», хором, «билет на выход».

Дополнительно: каждая спортивная глава начинается с вопроса «какой секрет здесь работает?» и заканчивается фразой «Повторим: …».

### 3.3. Принцип «сказать — показать — привести пример»

В заметках лектора у каждого ключевого тезиса три реплики: короткая фраза, жест/движение, бытовой пример. Это защищает от монотонного чтения слайда.

### 3.4. Адаптация 1–2 / 3–4 класс

- **1–2 класс:** не называть точные секунды/метры; оставить «быстрее/выше/дальше», жесты, игру реакции, три слова. Глав 7–8 можно сократить.
- **3–4 класс:** добавить числа (0,146 с; 6,31 м; 56,792 км), вопрос «почему?», «подробнее» в панели.
- В сценарии — отдельные пометки для каждого варианта.

**Итого:** 39 минут. Переходы и вопросы — внутри глав.

### 4.1. Спецификация глав

Для каждой главы: `тезис → 3D → действие → видимое изменение → повторение → fallback → критерий`.

#### Глава 1. Титул
- **Тезис:** мячом управляет не «магия», а силы.
- **3D:** макет стадиона, ворота 7,32×2,44 (масштаб), мяч, трибуны, 4 прожектора.
- **Действие:** орбита; кнопка «Ударить»; клик по мячу.
- **Изменение:** мяч летит с закруткой в верхний угол; сетка/конфетти.
- **Повторение:** вопрос «кто управляет мячом?»; анонс трёх секретов.
- **Fallback:** постер стадиона + кнопка «Показать схему полёта».
- **Критерий:** мяч виден, удар срабатывает, сброс возвращает мяч.

#### Глава 2. Три секрета
- **Тезис:** у любого спортивного результата три опоры.
- **3D:** три пьедестала; объект силы (мяч + стрела), объект вращения (мяч + спираль), объект точности (мишень).
- **Действие:** клик по пьедесталу/карточке; «Проверь память».
- **Изменение:** камера фокусируется, объект подсвечен, подпись/жест; в режиме памяти слова скрыты.
- **Повторение:** хором 2 раза, жесты.
- **Fallback:** три SVG-иконки + те же карточки.
- **Критерий:** все 3 секрета выбираются, память скрывает/показывает, сброс.

#### Глава 3. Футбол
- **Тезис:** сила задаёт скорость, вращение — форму полёта; точность — куда попадёшь.
- **3D:** мини-поле, ворота, стенка из 3 фигур, вратарь, мяч; траектория.
- **Действие:** сила 60–120 км/ч, закрутка −100…100, цель (3 кнопки/клик по воротам), удар, замедление, сброс.
- **Изменение:** реальная 3D-траектория с гравитацией/сопротивлением/Магнусом; дуга в метрах; вратарь реагирует; гол/сейв/мимо.
- **Повторение:** «Какое слово свернуло мяч?»; факт 35 м / ~130 км/ч / ~2,6 м.
- **Fallback:** постер + 2D-траектория на canvas с теми же ползунками.
- **Критерий:** 3 разных закрутки дают разные траектории; сила меняет время полёта; сброс.

#### Глава 4. Спринт
- **Тезис:** старт — это сила + быстрая реакция; реакцию тренируют.
- **3D:** дорожка, колодки, бегун, стартовый светофор.
- **Действие:** «На старт» → случайная задержка → зелёный → пробел/клик.
- **Изменение:** бегун бежит, показывается реакция, сравнение с 0,146 с; фальстарт при <0,1 с.
- **Повторение:** «Что нужно на старте? — сила и точность».
- **Fallback:** постер + таймер реакции без 3D.
- **Критерий:** 3 попытки, фальстарт, сброс, сравнение.

#### Глава 5. Шест
- **Тезис:** разбег запасает энергию; шест возвращает её в высоту.
- **3D:** дорожка, стойки, планка, мат, прыгун, гнущийся шест.
- **Действие:** скорость разбега 6,0–9,8 м/с; «Прыжок».
- **Изменение:** высота планки, изгиб шеста, энергия (кинетическая → упругая → потенциальная), успех/сбил.
- **Повторение:** «Куда ушла энергия? — в шест, потом в высоту».
- **Fallback:** постер + шкала энергии.
- **Критерий:** низкая скорость — не хватает, высокая — 6,31 м; сброс.

#### Глава 6. Велосипед и плавание
- **Тезис:** на большой скорости главный соперник — сопротивление среды; форма помогает.
- **3D:** велосипед с гонщиком; бассейн с пловцом; частицы потока.
- **Действие:** вкладки, ползунок «поза/обтекаемость» 0–100%.
- **Изменение:** поза, плотность частиц, скорость при той же мощности; сравнение.
- **Повторение:** «Почему наклоняются? — меньше сопротивление».
- **Fallback:** постер + два силуэта.
- **Критерий:** обе вкладки, ползунок меняет скорость и частицы, сброс.

#### Глава 7. Вращение везде
- **Тезис:** одно правило работает в разных мячах.
- **3D:** футбольный, теннисный, баскетбольный мячи; траектория/отскок.
- **Действие:** выбрать мяч; ползунок закрутки; направление.
- **Изменение:** вращение текстуры, дуга/нырок/отскок.
- **Повторение:** «Вращение управляет полётом — в футболе, теннисе, баскетболе».
- **Fallback:** постер + 2D-дуги.
- **Критерий:** 3 мяча, 2 направления, сброс.

#### Глава 8. Наука и рекорды
- **Тезис:** наука помогает измерять, тренировать и создавать материалы.
- **3D:** витрина с 5 объектами; подсветка.
- **Действие:** годы/объекты; «Рекорд-детектив».
- **Изменение:** камера/свет/карточка; старый/новый мяч.
- **Повторение:** «Наука — помощник спортсмена».
- **Fallback:** постер + список.
- **Критерий:** 5 объектов, карточки, сброс.

#### Глава 9. Викторина + финал
- **Тезис:** проверим три секрета; наука — командная работа.
- **3D:** кубок, 6 делений, конфетти.
- **Действие:** 6 вопросов, ответы, финал, «скажи соседу».
- **Изменение:** кубок растёт/качается, деления загораются, конфетти.
- **Повторение:** финальные три слова/жеста.
- **Fallback:** постер кубка + викторина.
- **Критерий:** 6 вопросов, правильные ответы, счёт, сброс, финал.

## 5. 3D и визуальный язык

### 5.1. Стиль
«Стадион-лаборатория»: светлый бумажный фон, зелёное поле, оранжевый акцент, синий воздух, чернильный текст. Низкополигональные модели на круглых пьедесталах, мягкие тени, тёплый направленный свет. Это **учебные модели**, а не точные копии; в README и на слайде 8 — оговорка.

Палитра:
- фон: `#F6F1E4` / `#E8F1E7`
- поле: `#2F7D4E`, тёмное `#14563A`
- акцент: `#F26B2A`
- воздух/вода: `#2E9CC4`
- чернила: `#14231E`
- бумага панели: `rgba(255,252,245,.94)`

Шрифты: `Unbounded` (заголовки, Cyrillic) + `Manrope` (текст, Cyrillic), локальные woff2, лицензия OFL.

### 5.2. Техническая сцена
- Three.js r170, собранный в один классический скрипт `assets/vendor/three.global.js` (UMD/IIFE). Без ES-модулей, чтобы работало с `file://`.
- Один `WebGLRenderer` с `alpha:true`; canvas переезжает в `.visual-layer` активной главы.
- 9 сцен создаются лениво и кешируются; активная сцена рендерится, остальные спят. Один WebGL-контекст.
- Каждая сцена: `scene`, `camera`, `controls` (OrbitControls), `update(dt)`, `dispose()`, `setAnchor(area)`, `labels`.
- Камера: `setViewOffset` сдвигает проекцию в якорную область справа от панели; при сворачивании/ресайзе пересчёт. Pivot — центр объекта, не центр экрана.
- Автоповорот: медленный, останавливается при взаимодействии; кнопка паузы в правом верхнем углу; `prefers-reduced-motion` отключает.
- Тени: 1 directional light + hemisphere; карта 1024/2048; на слабых — 1024. DPR ≤ 1.75.
- Raycast по клику (с отличием от drag) для выбора объектов; все основные действия также доступны кнопками/ползунками.
- HTML-подписи проецируются из 3D; скрываются под панелью/за экраном. Не более 3–4 на сцену.
- Fallback: если WebGL недоступен/контекст потерян — постер `assets/fallback/chapter-N.png` в той же якорной области + текст + кнопки без 3D.

### 5.3. Модели
Авторские процедурные модели: платформа, мячи (футбольный/теннисный/баскетбольный), ворота и сетка, манекены спортсменов, вратарь, стенка, дорожка, колодки, светофор, шест, планка, мат, велосипед, бассейн, кубок, витрина, секундомер, кроссовка. Без внешних GLB и fetch — это гарантирует офлайн-запуск. Модели подписаны как стилизованные учебные.

### 5.4. Производительность
- Целевой ноутбук: встроенная графика, Chrome/Edge/Firefox последних версий.
- 30–60 fps; анимации останавливаются на неактивных главах; `visibilitychange` — пауза.
- Никаких тяжёлых постэффектов, физдвижка и теней от каждого объекта.
- Проверить отсутствие утечек: повторный проход 9 глав 3 раза, контекст один, console без ошибок.

## 6. Оболочка презентации

- **Presentation:** одна активная глава, переходы, прогресс, прямой `#N`.
- **Панель:** слева, `clamp(340px, 31vw, 520px)`, прокрутка, сворачивание; restore вне панели; фокус.
- **Шапка:** номер/название главы, кнопки «Главы», «Три секрета», «Разминка», «Заметки», пауза 3D, полный экран.
- **Подвал:** назад/далее, точки, время главы.
- **Заметки:** правая шторка, сценарий главы, тайминг, повторы, ответы; плашка «видны на общем экране».
- **Индекс:** overlay со списком 9 глав и временем.
- **Викторина:** 6 вопросов, 3–4 варианта, ответ после клика, объяснение, счёт, сброс.
- **Клавиши:** ←/→/Space/PageUp/PageDown/Home/End; `F` fullscreen; `N` notes; `M` index; `S` secrets; `W` warmup; `T` panel; Esc закрывает верхний слой/панель.
- **Reduced motion:** без автоповорота и декоративных переходов; 3D остаётся управляемым.
- **Fullscreen refusal:** понятный toast, показ продолжается.
- **WebGL loss:** постер + текст, без зависания.

## 8. QA и приёмка

### 8.1. Обязательные проверки

1. **Геометрия:** для каждой главы `.scene` и `.visual-layer` = viewport ±3 px при открытой панели.
2. **Скриншоты:** каждая глава на 1366×768 и 1920×1080, панель открыта и скрыта; просмотреть глазами.
3. **3D:** каждая сцена рендерится, объект в якорной области, орбита/зум/сброс, пауза, подписи не под панелью.
4. **Интерактив:** каждый ползунок/кнопка/вкладка/выбор даёт видимое изменение; не только aria/текст.
5. **Навигация:** все входы, границы, быстрые повторные нажатия, `#N`, Home/End, отсутствие пустых кадров.
6. **Клавиатура:** Space/Enter на кнопках не листают; слайдеры работают стрелками; фокус виден.
7. **Fullscreen:** кнопка, `F`, `fullscreenchange`, отказ.
8. **Notes:** предупреждение, закрытие, фокус.
9. **Quiz:** 6 вопросов, правильные ответы, счёт, сброс, финал.
10. **Offline:** `file://` без сети, без 404, без console errors.
11. **WebGL off:** постер и управление.
12. **Reduced motion:** без автоповорота/декоративных переходов.
13. **Утечки:** 3 прохода, один canvas, нет роста числа контекстов/обработчиков.
14. **Текст:** нет горизонтального overflow, панель прокручивается, кнопки не под footer.

### 8.2. Инструменты

- Playwright (Chromium) + локальный HTTP-сервер для тестов; дополнительно `file://` smoke.
- Скриншоты в `qa/`; отчёт `docs/qa-report.md` с PASS/FAIL/NOT RUN и путями.
- Визуальная проверка — глазами по скриншотам, не только boundingBox.

### 8.3. Известные ограничения

- Телефон/планшет не проверяются и не поддерживаются (решение пользователя).
- Модели процедурные, стилизованные; это не фотoreal и не точная биомеханика.
- Числа рекордов могут устареть; в источниках указана дата проверки.
- 3D требует WebGL; при отказе — постер.

## 10. Риски и решения

| Риск | Решение |
|---|---|
| 9 3D-сцен тормозят | один renderer, ленивая сборка, сон неактивных, DPR cap, простые материалы |
| Canvas не работает с `file://` | классические скрипты, без модулей/fetch/GLB |
| 3D-объект за панелью | view offset от фактического rect панели, пересчёт при collapse/resize |
| Слишком сложный текст для 1 класса | короткие фразы, числа только в «подробнее», сценарий с упрощением |
| Повторение надоедает | жесты, движение, игра, смена формата; 5 точек, а не 10 |
| Модели выглядят «игрушечно» | единый стиль диорамы, свет, тени, подписи; честно назвать учебным макетом |
| Панель закрывает сцену | якорная область + подписи + скрытие панели |
| WebGL недоступен | постер + текст + кнопки |
