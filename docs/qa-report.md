## 5. Offline и отказ WebGL

**Offline:**
- Ресурсы: только локальные `assets/…`.
- Внешних `http://` / `https://` запросов — **0**.
- `requestfailed` — **0**, ответов ≥400 — **0**.
- `console.error` / `pageerror` — **0**.

**WebGL off:**
- Показан постер `assets/fallback/chapter-3.png`.
- Текст, панель, вкладки, викторина работают.
- Тост: «WebGL недоступен: показаны статичные схемы, текст и викторина работают».
- Скриншот: `qa/screenshots/webgl-off-chapter-03.png`.

**Reduced motion:** автоповорот отключён, сцена управляется вручную.

## 7. Известные ограничения

- 3D-модели процедурные и стилизованные; это учебный макет, не фотореализм и не инженерный симулятор.
- Масштаб футбольных ворот уменьшен для читаемости; числа дуги — учебные.
- Телефон/планшет не входят в объём и не тестировались (решение пользователя).
- WebGL обязателен для 3D; при отказе — статичные постеры.
- Для 4:3 при желании можно свернуть панель: сцена станет шире.
- Рекорды могут обновляться; дата проверки источников — 31.10.2026.
